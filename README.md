# DFMEA Automation Platform

A full-stack engineering workflow automation platform developed to streamline DFMEA evaluation processes.

## Problem

Traditional DFMEA evaluation involved significant manual effort, repetitive data entry, and fragmented record management.

## Solution

Designed and developed a MERN-based platform to digitize the complete workflow, enabling centralized data management, session persistence, automated report generation, and improved traceability.

## Tech Stack

- React
- Node.js
- Express
- MongoDB
- REST APIs

## Key Features

- Dynamic type-specific workflows
- Material database integration
- Session management
- Automated report generation
- Validation and completion tracking

## Impact

- Reduced engineering evaluation time by approximately 60%.
- Improved consistency across engineering assessments.
- Minimized manual documentation effort.
